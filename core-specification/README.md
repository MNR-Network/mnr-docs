# MNR Core Specification v1.0

## Project Information

**Project Name:** MNR Network

**Currency Name:** Miner Network Reward

**Ticker:** MNR

**Slogan:** Fair Mining. Real Utility.

---

## Mission

MNR Network is a community-driven cryptocurrency focused on fair CPU mining, long-term participation, and real-world utility.

The goal is to build an ecosystem where miners are rewarded not only through mining but also through marketplace participation, auctions, and community engagement.
